# Velvet Radio — план обновлений по версиям

План приблизительный: пункты можно менять, переносить между версиями и брать по одному.
Текущая версия: **1.0.0** (21 станция, качества до 320 kbps, зеркала и автопереподключение, названия песен, визуализатор,
перетаскивание станций, горячие клавиши и медиа-кнопки, светлая и тёмная тема).

Любые новые станции добавляем строго по правилам из [`ADDING-STATIONS.md`](ADDING-STATIONS.md).

## Не в плане (пользователь отказался)
История и «лайки» песен, таймер сна, обложки песен, добавление своих станций, эквалайзер и выравнивание громкости,
уведомления о смене песни, управление радио кликом по иконке в панели Chrome. Можно вернуться позже, если передумаем.

## 1.1 «Надёжность и удобство»
- [ ] **Самодиагностика потоков.** Раз в сутки тихо проверять все адреса и качества; в настройках показывать, какие упали или сменились.
- [ ] **Страница настроек.** Режим экономии трафика (брать качество ниже), размер запаса буфера (4 / 8 / 12 секунд) для слабого интернета, ссылка на горячие клавиши.
- [ ] **Управление с клавиатуры в окне:** `/` — в поиск, стрелки и Enter — выбор станции.
- [ ] **«Сообщить о неработающей станции»:** открывает чат в Telegram с уже заполненным текстом.

## 1.2 «Выбрать быстрее»
- [ ] **«Что играет везде».** В списке у каждой станции маленькой строкой текущая песня, не включая станцию. Опрос аккуратный, только пока окно открыто.
- [ ] **Фильтры по жанрам:** Поп, Рок, Шансон, Новости, Электроника и т.д.
- [ ] **Новые станции:** Energy, Авторадио, Юмор FM, Весна FM, Радио Дача (повторно искать рабочие потоки).

## 1.3 «Звук как у плеера»
- [ ] **Плавный переход между станциями** (затухание и нарастание), плавные пауза и старт.
- [ ] **Индикатор состояния потока:** тонкая точка (зелёная / жёлтая / красная) и реальный кодек (MP3 / AAC) в подсказке.
- [ ] **Автовозобновление при запуске Chrome** (по желанию, включается в настройках).

## 1.4 «Всегда под рукой»
- [ ] **Боковая панель Chrome.** Velvet Radio в боковой панели на всю высоту, не закрывается при переходах по сайтам, помещается весь список.
- [ ] **Синхронизация** избранного, порядка станций и выбранного качества между компьютерами через аккаунт Chrome.
- [ ] **Резервная копия:** выгрузка и загрузка избранного и порядка одним нажатием.

## 2.0 «Публикация»
- [ ] **Chrome Web Store:** скриншоты, промо-плитка в нашем стиле, описание, обоснование разрешений.
- [ ] **Два языка интерфейса** (русский и английский), переключатель в настройках.
- [ ] **Политика конфиденциальности:** ничего не собираем и не отправляем, это стоит написать прямо.
- [ ] **Проверка названия** «Velvet Radio» на занятость в магазине.

## Приоритеты (если делать по одному)
1. «Что играет везде» (1.2) — самая заметная фишка.
2. Боковая панель (1.4) — меняет сам способ пользоваться радио.
3. Самодиагностика потоков (1.1) — чтобы не гадать, почему «не играет».
