# Velvet Radio — расширение Chrome

Перед добавлением, изменением или проверкой радиостанций, потоков, качеств, зеркал, названий песен и логотипов
обязательно следуй правилам из файла ниже. Пользователю не нужно пересказывать их заново.

@ADDING-STATIONS.md

Коротко:
- Битрейт ставить только после замера реального потока; названиям потоков не верить.
- Кнопки качества — только реальные ≥128 kbps (максимум три), всё ниже — скрытая страховка; 64 на кнопки не выносить.
- У каждого качества должны быть зеркала и резерв; без выдумок: нет источника песен или потока — честно сообщить.
- Весь код внутри расширения, без remote code.
- Проверки только скрытые и без звука (пользователь может играть в игры); в конце убить тестовые процессы.
