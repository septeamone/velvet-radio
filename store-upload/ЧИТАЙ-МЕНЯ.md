# Velvet Radio: что и куда загружать в Chrome Web Store

Всё для страницы расширения лежит в этой папке. Папки пронумерованы по порядку заполнения. Все картинки уже нужного размера и формата (PNG без прозрачности, 24 бита), как требует кабинет.

## Карта: поле в кабинете, файл

| Где в кабинете (раздел «Описание продукта») | Что загрузить | Размер |
|---|---|---|
| Пакет (вкладка «Пакет», кнопка «Загрузить новый пакет») | `0-пакет/velvet-radio-1.7.0.zip` | 3,2 МБ, версия 1.7.0 |
| Значок магазина | `1-иконка/иконка-магазина-128x128.png` | 128×128 (рисунок 96×96 и прозрачное поле 16 px) |
| Глобальные скриншоты (до 5) | все 5 файлов из `3-русский (по умолчанию)/скриншоты/` | 1280×800 |
| Локализованные скриншоты, язык «английский — en» (до 5) | все 5 файлов из `4-английский/screenshots/` | 1280×800 |
| Маленькое рекламное изображение | `2-для обоих языков/малая-плитка-440x280.png` | 440×280 |

| Описание (русский, язык по умолчанию) | текст из `3-русский (по умолчанию)/описание.txt` | |

Порядок скриншотов задаётся именем файла (01, 02, 03, 04, 05): первый показывается на странице в первую очередь.

## Как перейти между языками
В кабинете сверху есть переключатель «Текущий язык редактирования»: «русский — ru (по умолчанию)» и «английский — en». Тексты и локализованные скриншоты заполняются для каждого языка отдельно.
Русские скриншоты кладём в «Глобальные» (их увидят все, у кого нет своих), английские в «Локализованные» для en. Так и сейчас устроена страница.

## Что в картинках
1. Радио со всего мира: главный экран с играющей станцией.
2. Страны с флагами: плитки.
3. Жанры каждой страны: панель жанров.
4. Избранное под рукой: вкладка «Избранное».
5. Две темы, один стиль: графит и слоновая кость.

Рекламные плитки общие для обоих языков: знак и название без текста на каком-либо языке.
Кадры сняты в настоящем окне расширения, играла настоящая станция. Названия песен на кадрах настоящие (проверены на отсутствие грубых слов).

## Перед загрузкой
- Пакет `0-пакет/velvet-radio-1.7.0.zip` уже собран (версия 1.7.0, разрешения не менялись: `offscreen`, `storage` и те же сайты станций). Его проверили отдельно: распаковали и прогнали тесты на самом архиве, всё работает.
- Для выпуска 1.7.0 новые скриншоты и тексты не обновлялись: в магазине остаётся прежнее описание и картинки (на них старый вид списка с тремя кнопками качества в строках). Это допустимо; при случае их стоит перегенерировать (`node tools/store-pack.mjs`).
- Пакет `velvet-radio-1.6.0.zip` в этой папке оставлен нарочно: с него тест обновления (`node tools/test-update.mjs`, `node tools/update-demo.mjs`) показывает, что увидит тот, кто обновился. После выхода следующей версии положите сюда её пакет.
- Краткое описание берётся из пакета (`_locales`), поэтому сначала загрузите пакет, потом тексты.
- Тексты написаны под новый интерфейс (в них больше нет слов про «жидкое стекло»).
- Размеры и формат картинок уже проверены. Вес каждой около 0,5–0,65 МБ.
- Эти картинки делает скрипт `node tools/store-pack.mjs` (нужен интернет, чтобы играла станция). Если окно расширения изменится, запустите его заново.
