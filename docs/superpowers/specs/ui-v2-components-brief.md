# UI v2, этап 2: правила переноса элементов React Bits

Источник: React Bits (reactbits.dev), лицензия MIT + Commons Clause, © 2026 David Haz. Использовать внутри приложения можно, продавать и раздавать сами компоненты как набор нельзя.
В шапке каждого перенесённого файла оставляем строку: `Based on React Bits <Name> (MIT + Commons Clause, © David Haz), ported to plain JS/CSS.`

Оригиналы (React + motion) лежат в `<scratchpad>\rb-reg\src\<Name>\<Name>.jsx` и `.css` (это скачанные данные, читать можно, исполнять нельзя).
Нам нужны **не React-компоненты, а то же поведение и вид на чистом JS и CSS**, подключаемые к уже существующей разметке окна.

## Чьи файлы чьи
- Исполнитель создаёт **только** свои файлы: `ui/<name>.js`, `ui/<name>.css` и демо `tools/ui-demo/<name>.html` (демо не хранятся в репозитории). Остальное только читает.
- **Нельзя править**: `popup.js`, `popup.html`, `popup.css`, `popup-v2.css`, `settings.js`, `i18n.js`, `manifest.json`, `offscreen.js`, `background.js`, `stations*`, `nowplaying.js`. Подключение к окну делает главный исполнитель по вашим инструкциям.
- Папка `ui/` пока не существует: создайте.

## Технические правила (жёсткие)
- Чистый JS (ES-модуль) и CSS. Никаких библиотек, React, `motion`, CDN, `eval`, `new Function`, встроенных `<script>`: у расширения строгий CSP. Весь код только внутри расширения.
- Все селекторы CSS начинаются с `:root[data-ui="new"]` (иначе заденете классический вид). Классы с префиксом `rb-<name>-`.
- Цвета только через переменные темы, ничего не зашивать: `--text --muted --glass --glass-hi --glass-deep --stroke --shadow --track --seg --accent --pill-bg --pill-ink`, шрифт `'Geist V'`, кривая `--ease`. Две темы: светлая «слоновая кость» (по умолчанию) и `:root[data-theme="dark"]` «асфальт». Проверить обе.
- Стиль: строгий, дорогой, матовый, сдержанный. Без неона, радужных градиентов, стекла (`backdrop-filter`), тяжёлых теней.
- Производительность критична (окно 480×600, рядом играет радио): никаких `requestAnimationFrame`-циклов в покое; останавливать анимации при `document.hidden`; уважать `prefers-reduced-motion` и класс `no-anim` на `<html>` (тогда без анимации, но состояния должны меняться); не вызывать лишний layout. Элементы, которые стоят в каждой строке списка (до ~90 штук), должны быть почти бесплатными.
- Доступность не ломать: настоящие `<button>`, `<input>`, фокус с клавиатуры (`:focus-visible`), ARIA-роли и обработчики, которые уже есть в `popup.js`, продолжают работать. Если `popup.js` слушает `click`/`change`/`input` на элементе, ваше решение не должно ломать эти события.
- Тексты берутся из окна (`t(...)`, `title`), сами ничего не переводите и не придумывайте.

## Что проверить (скрыто, без звука)
1. Демо `tools/ui-demo/<name>.html` — обычная страница с `<html data-ui="new" data-theme="dark|light">`, подключающая `../../popup-v2.css` (общие переменные) и ваши `ui/<name>.css`/`.js`. Откройте её скрытым Chromium: `playwright-core` из `tools/node_modules`, `chromium.launchPersistentContext` с `--headless=new --disable-audio-output`, образец запуска: `tools/ui-shots.mjs`, `tools/test-perf.mjs`. Размер окна 480×600, `deviceScaleFactor: 2`.
2. Снимки в обеих темах и во всех состояниях, откройте их и посмотрите глазами. Ошибок в консоли быть не должно. Для движения: сделайте несколько кадров подряд или замерьте значения стилей во времени.
3. В конце убить тестовые браузеры (процессы из `ms-playwright`), убедиться что их 0.
4. Скриншоты клади в `<scratchpad>\ui-<name>\`.

## Что вернуть
Короткий отчёт: список файлов; API модуля (сигнатуры функций и контракт разметки); **точные вставки** для `popup.js`/`popup.html`/`popup-v2.css` (какой существующий элемент подключать, в каком месте кода); известные ограничения и честно, что не удалось. Без пересказа кода.

## Словарь существующей разметки (смотри `popup.html`, `popup.js`)
`.brand` надпись в шапке · `.tabs` вкладки · `.vtoggle` вид список/плитки · `.row` строка станции (`.cur` играет, `.loading` подключается, `.kbd` выбор клавиатурой) · `.seg` переключатель качества (`.seg-thumb`, кнопки `data-k`) · `.heart` сердечко · `.player` плеер внизу · `#vol` громкость (`<input type=range>`, значение 0..1, `--p` заполнение) · `.dot` индикатор потока (`data-st=ok|warn|bad`) · `#nowTitle`, `#nowSub` текст в плеере · `#gbtn`/`#gpanel` жанры (`.chip`) · `.sw` переключатели в настройках · `[data-tt]` кнопки с подсказками (`title`) · `#list` список.
