# Velvet Radio 1.5 — спецификация

Дата: 2026-10-12. Ветка: `release-1.5`. Версия в `manifest.json`: `1.0.0` → `1.5.0`.
Один большой релиз (решение Jack). Название «2.0» зарезервировано за кардинальной переработкой.

## 1. Цель и главное условие

Каталог вырастает с 21 российской станции до ~450 станций из 29 направлений (Россия + 28 стран), расширение получает вкладку «Страны», два языка и обновлённое окно.
**Радио не должно сломаться:** движок `offscreen.js` почти не трогаем, каждый этап проверяется тем же скрытым тестом без звука, что и базовая версия.

## 2. Жёсткие ограничения (решения Jack)

1. **Никаких новых разрешений и хостов в `manifest.json`** (ни `sidePanel`, ни `alarms`, ни новых `host_permissions`). Причина: проверка магазина и повторное согласие у существующих пользователей. В конце сравниваем старый и новый манифест тестом.
2. **Эквалайзера нет.** Боковой панели нет (нужно разрешение).
3. Весь код внутри расширения, без remote code. Библиотеки только копией (флаги, hls.js).
4. Все станции строго по `ADDING-STATIONS.md` (обновлён 2026-10-12): **замер битрейта не нужен**, на кнопках заявленный битрейт ≥128 (макс. три, цель 128/256/320), но каждый поток обязательно проверяется на живое аудио; зеркала, логотип 128×128, потоков не выдумываем.
   **64 kbps** на кнопки никогда; скрытый запас `hid(64)` только в самом крайнем случае, когда иначе никак (поправка Jack). Существующие `hid(64)` у Дорожного и Relax в этапе 3 пересматриваем: оставляем только если без них у станции не остаётся запаса.
5. Проверки скрытые и без звука, тестовые процессы в конце убиваем.
6. Серверы только за пределами России (общее правило Jack); расширению серверы не нужны.

## 3. Объём

### 3.1 Исправления из ревью
- `background.js`: очередь записи состояния (гонка `setState`).
- `offscreen.js`, ветка `if (my !== session)` в `start`: полная очистка отброшенного соединения (`hls.destroy()`, `pause()`, `removeAttribute('src')`, `load()`).
- `background.js`: медиа-клавиша Play работает и в состоянии `error`.

### 3.2 Окно и интерфейс
- Окно шире: 420 → 480 px. Высота остаётся 600 (максимум Chrome для popup).
- Шапка и плеер ниже, чтобы в списке было видно больше станций (цель: +80–100 px под список).
- Нижняя плашка «Мой Telegram» убирается. Telegram становится круглой иконкой в шапке рядом с переключателем темы (тот же `.icon-btn glass`).
- В шапке кнопка языка RU/EN (тот же стиль).
- Вкладки: **Россия** · **Избранное** · **Страны**.
- Всё в едином стиле существующего дизайн-кода (стекло, акценты, анимации).

### 3.3 Вкладка «Страны»
- Две раскладки: список и плитки с флагом. Выбор запоминается (`chrome.storage.local`).
- Тап по стране открывает её станции (обычные строки) со стрелкой «назад».
- Общий поиск на вкладке ищет страны по названию на русском и английском («Германия», «Germany», «США», «USA», «Великобритания», «UK»…) и станции внутри открытой страны. Названия берём из `Intl.DisplayNames` для `ru` и `en` плюс короткий словарь псевдонимов (США/USA/America, Великобритания/UK/Britain и т. п.).
- Флаги: SVG, копия открытой библиотеки (MIT) в `flags/`, ~29 файлов. Эмодзи-флаги не используем: Chrome на Windows их не рисует.
- Россия во вкладку «Страны» не входит (у неё своя вкладка).
- Строки станций страны рисуются только при открытии страны, чтобы окно не тормозило.

### 3.4 Два языка
- Свой словарь `i18n.js` (ru/en): интерфейс, жанры, подсказки. Язык по умолчанию — язык Chrome, переключатель в шапке.
- Для магазина: `_locales/ru` и `_locales/en` (имя и описание), `default_locale: ru`. Разрешения не нужны.
- Названия станций — официальные, как есть. Жанры переводятся по ключам.

### 3.5 Станции
**Россия:** +~100 к текущим 21. **Страны (28):**
США, Великобритания, Германия, Франция, Италия, Испания, Нидерланды, Польша, Турция, Китай, Япония, Южная Корея, Индия, Бразилия, Мексика, Канада, Австралия, Аргентина, Швеция, ОАЭ, Казахстан, Беларусь, Армения, Азербайджан, Грузия, Узбекистан, Украина, Камерун.

**Количество:** ~10 на страну; **США и Великобритания — больше** (США ~30, Великобритания ~25). Если из России доступно меньше — берём сколько реально работает и пишем почему.

**Жанры по странам (правило):** состав жанров у каждой страны свой, по тому, что там реально популярно, примерно по 2 станции на жанр (а не 10 одинаковых поп-станций). Примеры плана:
- **США:** кантри — самая популярная станция; хип-хоп отдельным блоком: олд-скул, самая «хайповая» станция и ещё пара топовых; поп/Top 40, рок, R&B, джаз, новости/ток и т. д. (уточняется исследованием и замером).
- Китай: поп (C-pop), новости/CNR, музыкальные, традиционная музыка, классика.
- Бразилия: сертанежу, фанк, MPB, поп. Индия: болливуд, региональные. Япония: J-pop, рок, новости. Остальные страны — по тому же принципу.

**Как выбираем станции:** популярность по radio-browser.info (голоса/клики) и официальным плеерам, затем фильтр по правилам: нет ретрансляторов-перекодировок, нет любительских каналов, нет закрытых по региону (проверка с этого компьютера, как слушает пользователь из России).
**Откуда берём потоки:** официальные плееры, серверы групп, origin-серверы, Icecast-статусы, radio-browser как источник кандидатов (заявленному битрейту не верим, всё замеряем).
**Названия песен:** только где источник работает без новых разрешений (уже разрешённые хосты или CORS-источники). У большинства новых станций названий не будет, это честно.

#### 3.5.1 Шансон без цензуры
Проверено: `chanson.hostingradio.ru:8041/chanson-uncensored256.mp3` (audio/mpeg, `icy-br: 256`) и `chanson-uncensored128.mp3` (audio/mpeg), оба по http и https, CORS есть (визуализатор будет). 320 нет (404). Добавляем отдельной станцией с качествами 128 и 256.

### 3.6 Структура данных
- `stations/ru.js`, `stations/us.js`, … по файлу на страну; общий `stations.js` собирает всё. Поле `country` (ISO) и ключ жанра у станции. Остальной код получает станции из `stations.js`, как раньше.
- id новых станций: `ru-…` не нужен для старых (id сохраняем, чтобы не потерять избранное и порядок пользователей), у иностранных — префикс страны (`us-…`, `gb-…`).
- `tools/build.py` включает `stations/`, `flags/`, `_locales/` в сборку.
- Миграция: у существующих пользователей сохраняются избранное, порядок, качество (id не меняются). Проверяется тестом.

### 3.7 Остальное из ROADMAP
Настройки (экономия трафика, буфер 4/8/12 с), самодиагностика (при открытии окна раз в сутки, без `alarms`), клавиатура в окне (`/`, стрелки, Enter), «Сообщить о неработающей станции» (Telegram и почта), фильтры по жанрам, «Что играет везде» (только уже разрешённые хосты, пока окно открыто), плавные переходы между станциями, индикатор потока и кодек, автовозобновление при запуске Chrome (по настройке), синхронизация избранного/порядка/качества (`chrome.storage.sync`), резервная копия (экспорт/импорт).

### 3.8 Релиз «как в продакшене»
- `CHANGELOG.md` (формат Keep a Changelog), тег `v1.5.0`, GitHub Release с архивом и «Что нового».
- Описание для магазина на русском и английском: короткое и подробное. Блок «Что нового» простым языком, без технических деталей (например, «Больше станций со всего мира», «Страны и флаги», «Русский и английский», «Улучшена стабильность потока»).
- Графика для магазина по размерам из старой публикации: 3 скриншота 1280×800 и малая промо-плитка 440×280, перегенерированные под новый интерфейс и новые тексты. Исходные скрипты (`shots.mjs`, `tile.mjs`) лежат во временной папке прошлой сессии, их копируем в `tools/store-assets/` и обновляем. Старые версии картинок остаются на рабочем столе.
- Обновление `README.md`, `ROADMAP.md`, `PRIVACY.md` (если меняется то, куда ходит расширение), `ADDING-STATIONS.md` (новая структура, страны, жанры, CORS-запись, инструменты).
- Загрузка в Chrome Web Store делается Jack вручную (вход в аккаунт); готовлю архив и тексты.

## 4. Инструменты (этап 0)
- `tools/probe.py`: кандидаты (radio-browser и шаблоны адресов) → проверка, что вернулся живой аудиопоток (не заглушка/404), кодек, CORS, заявленный битрейт (из адреса, `icy-br`, каталога), сравнение IP зеркал, таблица результата. Замер битрейта не делаем. Паузы между запросами.
- `tools/check-catalog.mjs`: быстрый замер всего каталога (основа самодиагностики).
- `tools/test-playback.mjs`: скрытый Playwright-тест без звука. Быстрый режим (15 с, все станции и качества: играет ли, kbps) и полный (60 с: заикания, зеркала, понижение качества, ошибка) на выборке и на всём, что затронуло движок.
- Тест манифеста: сравнение `permissions` и `host_permissions` с 1.0.0.

## 5. Этапы и проверки
0. Ветка (сделана), инструменты, базовый замер 1.0.0 → **проверка:** тест на 21 станции даёт эталон.
1. Исправления из ревью → тест эталона, без регресса.
2. Окно: размеры, Telegram, язык, флаги, вкладка «Страны» на текущем каталоге → ручной скрин светлой/тёмной темы, длинные названия, оба языка.
3. Структура данных + русские станции → быстрый тест всех, полный на новых.
4. Страны → то же; логотипы контрольными листами глазами.
5. Остальные функции из 3.7 → тесты по каждой, отдельно на заикания при плавных переходах и автовозобновлении.
6. Итог: полный прогон, тест манифеста, миграция избранного, сборка, документы, графика, `CHANGELOG`, релиз-пакет.

## 6. Риски
| Риск | Что делаем |
|---|---|
| Закрытые по региону потоки, особенно США и Китай | Проверяем из России, берём только рабочие, честно пишем, если станций меньше 10 |
| Долгие тесты (450 станций) | Быстрый режим для всех, полный для выборки |
| Тормоза списка | Рисуем только открытую вкладку/страну |
| Плавные переходы и сторож | Меняем только громкость `audio`, тест на заикание |
| Утечка избранного пользователей при смене структуры | id старых станций не меняются, тест миграции |
| Названия песен у новых станций | Нет новых разрешений, значит чаще нет названия (осознанно) |
| Логотипы 450 штук | Скрипт сбора и контрольные листы глазами |

## 7. Не входит
Эквалайзер, боковая панель, таймер сна, свои станции, история песен, уведомления, обложки песен и всё остальное из «Не в плане» ROADMAP.
